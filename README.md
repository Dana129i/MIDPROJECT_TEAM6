# 프로젝트명: 학생 성적 요인 분석

## ✏️ 프로젝트 개요
- 학생 성적에 영향을 미치는 다양한 요인을 분석하는 프로젝트입니다.
- 학생의 학습 참여도, 부모의 학교 만족도 등 여러 변수들이 성적에 어떤 영향을 미치는지에 대한 가설을 설정하고, 이를 실제 데이터를 통해 확인합니다.

## 🛠️ 사용 기술
- **Python**: 데이터 분석 전반에 활용
  - `pandas`: 데이터 전처리
  - `matplotlib`, `seaborn`: 데이터 시각화

## 🔍 분석 가설 및 결과
> 아래 가설 및 분석 결과는 팀 프로젝트 중 **개인이 수행한 부분**을 정리한 것입니다.  
> 전체 프로젝트 발표 자료에는 팀원들의 추가 분석도 포함되어 있습니다.

### 가설 설정
**<학생 참여도 부문>**
1. 결석이 적을수록 학생의 성적이 높을 것이다.
2. 학습에 적극적으로 참여한 학생일수록 성적이 높을 것이다.
   - 손들기, 토론 참여(적극적 참여)
   - 리소스 방문, 공지사항 열람(소극적 참여)

**<보호자 참여도 부문>**
1. 책임이 있는 부모가 엄마로 입력되어 있는 학생의 성적이 더 높다.
   - 부모-자녀 성별 함께 고려
2. 학부모가 학교에 만족할수록 학생 성적이 높다.

### 분석 결과
- 결석이 적은 학생일수록 평균 성적이 높음
- 손들기 및 **리소스 방문** 횟수가 많을수록 평균 성적이 높음
  - 수치는 상대적으로 낮으나 토론 참여, 공지사항 열람과도 성적 간 **양의 상관관계** 존재
- 책임이 있는 부모가 엄마로 입력되어 있는 학생의 평균 성적이 더 높음
  - 특히 1등급에 모녀 관계인 경우가 가장 많이 분포되어 있음
- 학부모가 학교에 만족할수록 학생의 평균 성적이 높음
